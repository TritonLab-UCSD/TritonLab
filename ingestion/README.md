# Ingestion
Connectors that pull source data into the `raw` schema.
- `openalex/`: researchers and papers (Week 1)
- `grants/`: NIH RePORTER or NSF awards (Week 2)
- `scrapers/`: faculty directories (Week 1) and lab websites (Week 2)
Rules: respect robots.txt, rate-limit, send a contact email in the User-Agent, cache responses.
